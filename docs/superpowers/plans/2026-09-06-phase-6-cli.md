# Phase 6.2: `@passwerk/cli` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `passwerk` binary (`audit`, `extract`, `emit`, `gaps`, `obligations`, `tools`, `chat`) plus the demo script, so scripts and CI get a no-LLM entry point and the definition of done of Phase 6 is met.

**Architecture:** The CLI is an adapter over the server's tool registry: every command parses its input with the tool's own Zod shape and calls the tool handler in-process with a `ToolContext` built from injected io (`stdout`, `stderr`, `fs`, `env`, `clock`). `run(argv, io)` returns the exit code; `bin.ts` is the only Node-bound file. `chat` is a manual Anthropic tool loop over the same registry, with the Anthropic client injected so tests script it and nothing contacts the network.

**Tech Stack:** TypeScript strict / ESM / NodeNext, commander 15.0.0, zod 4.5.4 (`z.toJSONSchema`), `@anthropic-ai/sdk` 0.123.0 (lazy import), vitest 4, biome 2.

**Spec:** `docs/superpowers/specs/2026-09-05-phase-6-mcp-server-skill-cli-design.md`, section 5 (commands, exit codes) and section 6 (tests, definition of done). ADR D-031.

## Global Constraints

- Dependency order `rules`, `core`, `server`, `cli`; the CLI imports the server registry, never core's internals for domain rules.
- No network at runtime except `chat`, which reads the key from `ANTHROPIC_API_KEY` only and imports `@anthropic-ai/sdk` lazily inside the command.
- Default chat model `claude-sonnet-5` (spec section 5).
- Exit codes: `audit`/`emit` 0 valid, 1 valid_with_warnings, 2 invalid, 3 usage or unreadable input; `gaps` 0 complete, 1 open, 3 usage; `obligations` 0 required, 1 not_required, 2 insufficient_input, 3 usage; `extract`, `tools` 0 or 3; `chat` 0 finished, 2 loop bound, 3 missing key or usage.
- Deterministic output: `canonicalJson` for `--json`; the only wall clock is `bin.ts`.
- Versions must be at least 3 days old (pnpm `minimumReleaseAge`): commander 15.0.0 (2026-05-29), `@anthropic-ai/sdk` 0.123.0 (2026-09-01).
- Conventional Commits, one PR (`feat/phase-6-cli`).

### Task 2: `invoke` and `audit`

**Interfaces:**

- `invoke(name, input, ctx): Promise<{ structured: Record<string, unknown>; text: LangText; isError: boolean }>`: parses `input` with `z.object(tool.inputSchema)`, calls the handler, catches like the server's `errorResult` (PassportDraftError → `{ error, findings }`, ZodError → `{ error }`, other → `{ error }`).

### Task 6: chat tools, loop, skill sync

**Files:** `src/chat/tools.ts`, `src/chat/loop.ts`, `src/chat/skill.ts` (generated), `scripts/sync-skill.mjs`, `src/commands/chat.ts`, `test/chat.test.ts`, `test/skill.test.ts`.

**Interfaces:**
- `type CreateMessage = (params: Anthropic.MessageCreateParamsNonStreaming) => Promise<Anthropic.Message>` (type-only SDK import).
- `anthropicTools(): Anthropic.Tool[]` from `TOOLS`, `input_schema = z.toJSONSchema(z.object({...inputSchema, lang}), { io: 'input' })`.
- `runAgentLoop({ createMessage, model, system, message, maxTurns, ctx, lang, onEvent })` → `{ status: 'finished' | 'bound'; turns: number; finalText: string }`.
